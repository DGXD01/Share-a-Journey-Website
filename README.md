- 由整个团队共同完成

另外，每位组员都要提交一份对自己和其他成员贡献、参与情况的评分表。评分表需要单独上传到 Stream，没有提交会影响个人成绩。

## 团队角色

每位组员分配一个角色。角色可以讨论后调整，同一个角色最多可以由两个人共同负责。

### FearlessLeader

团队负责人，主要工作包括：

- 和组员一起分配任务
- 主持讨论
- 提醒大家截止日期
- 通过指导老师与客户沟通
- 在正式提交前，把初步设计交给指导老师查看
- 对全部小组交付物负责

原文还提到后文有 Share Your Design 的说明，但文档可见页面中没有单独列出这部分内容，提交前需要留意课程平台或老师给出的补充信息。

### DesignGuru

负责检查页面是否合理运用对齐、对比、邻近性和重复等设计原则，并确保示例页面布局具有可用性和无障碍性。

主要参与所有设计相关工作，尤其是 Sample Page Layout 的布局格式，并在其他成员协助下完成 Presentation。

### TextMaster

负责网页文字内容，包括标题、段落和列表的写法。标题要有吸引力，段落要简洁，列表要醒目。

主要在本组成员协助下完成 Analysis Report，并为 Sample Page Layout 提供文字内容。

### PixelMeister

负责网站的颜色和图形设计，包括：

- 选择配色方案
- 说明选择该配色方案的理由
- 在其他成员协助下完成 Sample Page Layout

## 完成步骤

### 1. 选择客户

先和组员讨论本组对应的客户，了解客户的业务领域、经营内容和主要服务。

### 2. 分析

完成以下四项调查：

1. 找出客户对网站的三大期望
2. 确定网站的目标受众
3. 找到三个竞争对手或类似网站
4. 使用 Web Design Best Practices Checklist 分析竞争网站

每个竞争网站需要写出两个优点和两个缺点。

分析结果要整理成一份两页的 Analysis Report，内容覆盖以上四项调查。

### 3. 设计

设计部分需要完成以下内容：

1. 选择配色方案，并说明理由
2. 从 jello、liquid、ice/frozen 中选择页面布局类型，并说明理由
3. 为标题、副标题、正文、页脚等内容选择字体、字重和字号，并说明理由
4. 制作 Sample Page Layout
5. 制作 Presentation

Sample Page Layout 可以从以下软件中选择：

- Adobe Macromedia Dreamweaver
- Adobe Macromedia Fireworks
- Microsoft PowerPoint
- Microsoft Word
- Adobe Photoshop

页面内容必须自己制作，包括自己的 logo 或 banner。

Presentation 使用 Microsoft Word 或 Microsoft PowerPoint，内容需要包含：

- 目标受众
- 客户对网站的期望
- 配色方案
- 页面布局类型
- 所选字体
- Sample Page Layout 文件的 URL

展示方式要有吸引力，能够向客户讲清楚设计思路。

### 4. 制作演示视频

视频由全组共同完成，时间不超过 15 分钟。每位成员负责讲解自己的部分，视频中要能看出团队分工和合作。

### 5. 提交

- 三个主要成果打包为 ZIP，通过 Stream 提交
- 演示视频通过 Stream 提交
- 每位成员分别上传个人和组员贡献评分表
- 具体截止日期以 Stream 提交页面显示的时间为准

## 评分标准

本次小组作业总分 64 分：

| 项目 | 分值 |
|---|---:|
| Analysis Report | 15 |
| Sample Page Layout | 24 |
| Presentation | 15 |
| Individual Participation/Contributions | 10 |
| 合计 | 64 |

### Analysis Report，15 分

每个评分项分为 3 分、1.5 分和 0.5 分三档。

| 评分项 | 3 分 | 1.5 分 | 0.5 分 |
|---|---|---|---|
| 客户的三项期望 | 三项期望都写清楚 | 写出了三项期望，但表述不清楚 | 少于三项期望 |
| 目标受众 | 清楚描述年龄、性别、兴趣和社会经济特征 | 描述不清楚或缺少部分标准 | 没有描述，或者描述与网站目的无关 |
| 竞争网站 | 列出三个竞争对手或类似网站的 URL | 列出的网站少于三个 | 没有列出，或者所列网站并非竞争网站或类似网站 |
| 竞争对手优缺点 | 每个网站清楚写出两个优点和两个缺点 | 每个网站清楚写出的优缺点少于两个 | 没有写，或者优缺点不清楚 |
| 写作规范 | 结构清楚，句子完整，语法和拼写正确 | 句子完整，但结构略乱，或者语法和拼写错误少于三个 | 句子不完整，或者存在三个以上语法和拼写错误 |

### Sample Page Layout，24 分

共六个评分项，每个评分项分为 4 分、2 分和 1 分三档。

| 评分项 | 4 分 | 2 分 | 1 分 |
|---|---|---|---|
| 目标受众 | 原文为 --- | 示例页面能吸引目标受众 | 示例页面不能吸引目标受众 |
| 页面布局 | 原文为 --- | 遵循所有网页设计最佳实践 | 缺少页面布局，或者没有遵循大部分最佳实践 |
| 导航 | 遵循所有网页设计最佳实践 | 遵循大部分最佳实践，不合规之处不超过三个 | 缺少导航，或者没有遵循大部分最佳实践 |
| 颜色与图形 | 遵循所有网页设计最佳实践 | 遵循大部分最佳实践，不合规之处不超过三个 | 缺少颜色或图形设计，或者没有遵循大部分最佳实践 |
| 文字内容 | 遵循所有网页设计最佳实践 | 遵循大部分最佳实践，不合规之处不超过三个 | 缺少文字内容，或者没有遵循大部分最佳实践 |
| 无障碍性 | 原文为 --- | 遵循所有网页设计最佳实践 | 缺少无障碍设计，或者没有遵循大部分最佳实践 |

原文评分表中，目标受众、页面布局和无障碍性的 4 分栏都写着 ---。这里可能是原表缺项，提交前最好向老师确认具体标准。

### Presentation，15 分

共五个评分项，每个评分项分为 3 分、1.5 分和 0.5 分三档。

| 评分项 | 3 分 | 1.5 分 | 0.5 分 |
|---|---|---|---|
| 客户期望 | 能明确看出网站方案会满足客户期望 | 方案可能无法完全满足所有客户期望 | 看不出方案如何满足客户期望 |
| 目标受众 | 清楚描述年龄、性别、兴趣和社会经济特征 | 描述不清楚或缺少部分标准 | 没有描述，或者描述与网站目的无关 |
| 外观表现 | 内容呈现得美观、有趣 | 内容还可以呈现得更有吸引力 | 缺少呈现效果，或者外观影响信息表达 |
| 设计说明 | 清楚说明配色、页面布局类型和字体 | 配色、布局和字体说明不清楚，或者缺少部分内容 | 没有说明，或者相关内容缺失 |
| 写作规范 | 结构清楚，句子完整，语法和拼写正确 | 句子完整，但结构略乱，或者语法和拼写错误少于三个 | 句子不完整，或者存在三个以上语法和拼写错误 |

### Individual Participation/Contributions，10 分

每位成员都要评价自己和组内其他成员的表现。评分表中每一列只能勾选一个分数。

| 分数 | 标准 |
|---|---|
| 5 分 | 几乎每天都能沟通并完成高质量工作，愿意合作，也能及时完成自己负责的角色任务 |
| 4 分 | 每周多次沟通并完成高质量工作，愿意合作，也能及时完成自己负责的角色任务 |
| 3 分 | 只在必须沟通时才出现，或者合作程度一般，或者只是勉强、及时地完成角色任务 |
| 2 分 | 很少沟通、不愿合作，或者工作质量较差、经常迟交 |
| 1 分 | 基本没有为团队作出积极贡献，属于最可能被团队排除的成员 |

这部分在作业说明中写的是 10 分，但评分表只列出 1 到 5 分，原文没有说明如何换算成 10 分。提交前需要向老师确认。

## 提交前检查

- 客户和组号是否对应正确
- 是否写出客户的三项期望
- 是否清楚说明目标受众的年龄、性别、兴趣和社会经济特征
- 是否列出三个竞争对手或类似网站
- 是否为每个网站写出两个优点和两个缺点
- Analysis Report 是否为两页
- 是否说明配色、页面布局和字体的选择理由
- Sample Page Layout 是否使用了原创内容，并包含 logo 或 banner
- Presentation 是否包含受众、客户期望、配色、布局、字体和样页 URL
- 视频是否不超过 15 分钟，每位成员是否都有讲解
- 三个主要成果是否已打包为 ZIP
- 视频和个人贡献评分表是否上传到 Stream
- 最后确认 Stream 中显示的实际截止时间
